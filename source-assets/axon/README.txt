AXON SURGICALS - Vector Logo Package
=====================================
Version A (Original Colours): colours sampled from the reference artwork.
  AXON #01458C | SURGICALS + side rules #029997 | triangle accent #039C99
  Tagline #013E81 | emblem: fitted blue/teal gradients
Version B (Grey Wordmark): AXON letters #5A5A5A; every other element identical to Version A.

All lettering (AXON, SURGICALS, Better Surgical Solutions) is reconstructed as vector outlines
traced from the original artwork, one editable path per letter - no fonts are needed to open,
print or edit any file.

06_Source_Working_File  MASTER working file - START HERE.
  AXON_Surgicals_MASTER_Working_File.svg  Both versions in one document, on two named pages. Each contains:
     Emblem             > A Monogram (upper body, inner bevel, lower leg, leg shadow) | Swoosh | Medical Cross
     Wordmark AXON      > AXON Letters (A, X, O, N) | A Triangle Accent
     SURGICALS          > SURGICALS Letters (9) | Side Rules (left, right)
     Tagline            > Better | Surgical | Solutions (one path per letter)
  Every shape is a separately named, selectable vector object with live, editable gradients.
  Best opened in Inkscape (free): pages and layers show natively.

01_SVG   Layered SVG per version.
02_AI    Illustrator files, one per version, 8 named layers in 4 groups (PDF-based .ai, see note).
03_PDF   Two-page A4 landscape PDF: page 1 Original Colours, page 2 Grey Wordmark. 100% vector.
04_EPS   EPS (PostScript Level 3), 100% vector including gradients.
05_PNG   5000 px wide: *_transparent.png and *_white-preview.png.

Note on Illustrator: if the .ai layers appear as groups in your Illustrator version, select them in
the Layers panel and choose Release to Layers (Sequence) from the panel menu.
Colour mode is RGB. Have your printer convert to CMYK/Pantone for press work.
